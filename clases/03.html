¿Qué es el Internet?

"Internet es como una gran red de información que conecta computadoras de todo el mundo."

La Metáfora de la Biblioteca

🏢 Servidores

Son los estantes gigantes que guardan toda la información de las páginas web.

🧐 Navegadores

Son los lectores (como tú) que usan Chrome o Firefox para ver los libros.

📍 Dirección IP

Es el "número de casa" de tu computadora para que la información sepa a dónde ir.

📖 Sitio Web

Es un libro completo con muchas páginas llenas de fotos, juegos y videos.

Navegando en la Web

Navegadores

Sirven para entrar y usar los sitios web.

Motores de Búsqueda

Sirven para encontrar información específica.

Tips de Seguridad:

  • HTTPS y Candado: Siempre verifica la barra de direcciones.
  • Descargas: Nunca bajes nada sin permiso de un adulto.
  • Privacidad: No compartas nombre, teléfono o escuela.

Mayúsculas y minúsculas

1. Longitud

Debe tener al menos 8 caracteres (letras o números).

2. Variedad

Mezcla Mayúsculas, minúsculas, números y símbolos (como #, $ o !).

3. Sin Info Personal

No uses tu nombre, tu fecha de nacimiento o el de tu mascota.

4. Única y Original

No uses "123456" o "contraseña". ¡Crea una llave secreta diferente para cada juego!

Tiempo de Uso

Es importante regular el tiempo que pasamos en tablets y celulares.

  • Recomendado: Máximo 1 a 2 horas al día.
  • ¡No olvides realizar actividades fuera de las pantallas! (Jugar, leer, dibujar).

Contenido Apropiado

💡 ¿Cómo asegurarnos?

Usa tu año real de nacimiento al crear cuentas para que las plataformas filtren el contenido. Si ves algo que dice "no apto para niños" o que incluye violencia, ¡no lo consumas!
